### [P2P Messaging](https://github.com/sil6428/P2P-messaging) — learning cryptography by making it argue with a network

A collaborative learning prototype with verified peers, password-protected Ed25519/X25519 identities, ChaCha20-Poly1305 messages, encrypted history, replay protection, and 72 automated tests. It also documents what it **doesn’t** safely solve yet.

### [File Integrity Monitor](https://github.com/sil6428/file-integrity-monitor) — tiny tool, very suspicious personality

A dependency-free SHA-256 monitoring engine with CLI automation and a local Integrity Desk. It caught 45 of 45 controlled changes across a 500-file fixture set.

### [Interactive portfolio](https://github.com/sil6428/affan-portfolio) — the serious portfolio has a secret level

The accessible route is a fast case-file portfolio. The optional route is a Three.js cyber-lab and simulated desktop because a plain projects page felt too easy.

### [Secure File Transfer](https://affan-shaikh.pages.dev/log/secure-file-transfer) — private source, public receipts

An authenticated TLS service and loopback-only interface with recipient isolation, resumable uploads, two-sided SHA-256 verification, and tamper quarantine.
