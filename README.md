## What I build

- **Arch:** secure messaging, publishing, moderation, access control, and community tools
- **Password Manager:** a Python CLI with password generation, validation, and encrypted storage
- **Network Labs:** VLANs, trunking, DHCP, STP, inter-VLAN routing, and routing practice in Cisco IOS
- **Event Planner:** a Node.js tool for adding, editing, and removing events
